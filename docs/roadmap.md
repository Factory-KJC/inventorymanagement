# 再構築ロードマップ

## Phase 0 — 設計確定（完了）

- 用語、ユースケース、MVP範囲を確定
- EPSON TM-T90II TM902UE211を家庭内LANへ有線接続し、80mm紙で使用
- NetumScan NSL8BLをUSB-HID（2.4GHzレシーバー優先）で使用
- LinuxサーバーをHTTPS経由で外出先から利用

完了条件: `product-concept.md` と `architecture.md` の未決事項が解消している。

## Phase 1 — APIの縦切り

- 新ソリューションとモジュール構成
- PostgreSQL、EF Core Migration、開発用シード
- 商品登録、入庫、消費、在庫一覧、履歴
- ドメインルールとAPIの自動テスト

完了条件: APIだけで「登録→入庫→消費→履歴確認」が再現できる。

## Phase 2 — スマートフォンPWA

- ホーム、検索、在庫一覧、商品詳細
- ワンタップ消費、入庫、期限入力
- 買い物リストと購入済み操作
- インストール可能なPWA、通信失敗時の安全な再送

完了条件: 日常操作にPCを必要としない。

## Phase 3 — Windowsクライアント

- .NET 8 WPFへの刷新
- APIクライアント、認証、安全なトークン保管
- 連続スキャン入庫、棚卸、フィルタ、CSV
- デバイスなしで試せる疑似スキャナ

完了条件: 50件の連続登録と棚卸が安定して行える。

## Phase 4 — サーマル印刷

- 58/80mm用買い物リストレイアウト
- テキスト/PDFプレビュー実装
- Linux Print Worker、ESC/POSアダプタ、印刷状態、再印刷
- 実機で日本語、改行、紙切れ復帰を検証

完了条件: 印刷失敗が在庫データへ影響せず、同じ内容を再印刷できる。

## Phase 5 — 運用

- DockerまたはWindowsサービスとして配備
- 自動バックアップと復元試験
- HTTPS、監視、ログローテーション
- 旧試作データの一度限りの移行ツール

## 確定した実行環境

- サーバー: Linux
- 利用範囲: 自宅LANおよび外出先
- プリンタ: EPSON TM-T90II TM902UE211（80mm、有線LAN 100BASE-TX/10BASE-T）
- スキャナ: NetumScan NSL8BL（USB-HID、2.4GHz、Bluetooth対応）

## 実装時に環境変数で決める項目

- 公開ホスト名
- VPN限定または一般インターネット公開
- LinuxディストリビューションとCPUアーキテクチャ
- バックアップ保存先と保持期間
