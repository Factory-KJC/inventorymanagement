## 1. 現在地

2026-08-29時点で、`WebAPI.Tests`は34件成功しています。PostgreSQL専用の1件は接続文字列を指定した環境で実行するため、通常実行ではスキップされます。`HomeStock.Windows.Tests`は7件成功し、商品・保管場所の登録・更新・論理削除・復元APIの要求、PWA共通機能と初回登録APIの要求、50件連続入庫時の成功数と冪等性キーの一意性を検証しています。

- 逆仕訳による在庫操作の取消し、二重取消しと負在庫の防止
- HTTP APIによる商品登録、入庫、消費、履歴、買い物候補生成の一連の操作
- 買い物完了からの一括入庫と、再送時・再変換時の二重計上防止
- 印刷用データが未購入項目だけを品名順で返し、商品単位を付与すること
- 既存の買い物リストへの手動項目・補充提案の追加
- ダッシュボード一覧のページサイズ制限
- PWAアプリシェルとインストール用Manifestの配信
- IndexedDB再送キューによる冪等キー維持と401時のキュー保護
- サインアウト時の認証情報・画面データの消去
- 初回セットアップトークン、ログインレート制限、更新トークンのローテーションと再利用拒否

HTTP統合テストではSQLiteのインメモリDBを使用しています。PostgreSQL固有の挙動を含む統合試験はまだありません。
