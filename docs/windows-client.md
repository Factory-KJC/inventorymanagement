# Windowsクライアント利用ガイド

Phase 3のWindowsクライアントは `WinApp/HomeStock.Windows.sln` にあります。.NET 10 MAUIのWindows専用ターゲットで、WinUI 3上にMVVMで実装しています。旧 `WinApp/InventoryManagementWin` は比較用の試作であり、新規開発には使用しません。

## 起動

Windows上でAPIを起動した後、次のコマンドを実行します。

```powershell
dotnet run --project WinApp/HomeStock.Windows/HomeStock.Windows.csproj
```

1. API URL、ユーザー名、パスワードを入力してログインします。
2. 入庫先の保管場所を選択します。
3. NetumScan NSL8BLをUSB-HIDモードか2.4GHzレシーバーで接続し、JANコード末尾にEnterを送る設定でスキャンします。

ユーザーが未登録の場合は、同じ接続欄でユーザー名、12文字以上のパスワード、必要に応じて初回設定トークンを入力し、「初回登録」を押します。登録後に「ログイン」を押してください。

更新トークンはWindows資格情報マネージャーへ保存されます。パスワードとアクセストークンは保存しません。ログアウトすると保存済みの更新トークンを削除します。

## デバイスなしの確認

「疑似JAN」へ8桁または13桁のJANコードを入力し、「疑似スキャン」を押します。実機と同じ商品検索・入庫処理を通ります。

未登録のJANコードをスキャンすると「商品・保管場所登録」タブへ移動し、読み取ったJANコードが登録欄へ引き継がれます。商品名、単位、必要に応じて補充点と目標在庫を入力して商品マスターへ登録してください。登録後は同じJANコードを再スキャンして入庫できます。

Windowsで行う管理作業として、商品マスター登録に加えて保管場所名と表示順の登録にも対応しています。

## PWAと共通の日常操作

- 「ホーム」で登録商品、在庫不足、7日以内期限、買うものの件数と期限間近の在庫を確認できます。
- 「商品一覧」と「保管場所一覧」で登録済みマスターを確認できます。商品一覧は商品名またはJANコードで絞り込めます。
- 一覧で項目を選択して「編集」を押すと、商品の名称・JANコード・単位・補充点・目標在庫、または保管場所の名称・表示順を後から変更できます。
- 一覧の「削除」は確認ダイアログで承認した場合だけ実行されます。削除は論理削除で、既存在庫と履歴は保持されます。
- 2文字以上の名称で新規登録すると、同一または部分一致する削除済み項目がある場合に復元候補を表示します。復元を選ぶと元のIDと履歴を引き継ぎ、入力中の内容で更新します。
- 「在庫一覧・棚卸」で商品、保管場所、数量、期限を指定した通常入庫と、商品・保管場所を指定した消費を記録できます。
- 「買い物リスト」で手動項目の追加、補充点を下回った商品の提案、購入済み・未購入の切り替えができます。

PWAのService Worker、ホーム画面へのインストール、ブラウザーのIndexedDB再送キューはWeb固有機能のためWindowsクライアントには含まれません。Windowsクライアントの在庫操作はAPIの冪等性キーを使用し、重複計上を防ぎます。

## 棚卸、フィルタ、CSV

- 在庫一覧の「絞り込み」は商品名、JANコード、保管場所を対象にします。
- 棚卸は対象ロットを選択し、実数を0以上で入力して調整します。
- CSV出力は画面で絞り込まれた行をUTF-8 BOM付きで保存します。

## 検証

```powershell
dotnet build WinApp/HomeStock.Windows.sln
dotnet test WinApp/HomeStock.Windows.Tests/HomeStock.Windows.Tests.csproj
```

自動テストではHID入力の集約、50回の連続スキャンがすべて入庫されて冪等性キーが重複しないこと、PWA共通機能のAPI要求と初回設定トークンを検証します。実機固有のキーボード配列、読取音、接続復帰は利用するNSL8BLで最終確認してください。
